# 구현 작업 목록

기준 문서 `docs/설계서.md`. 마일스톤 번호(M1~M13)와 절 번호는 설계서와 같다. 한 작업은 가능하면 한 커밋이다. 체크는 "완료 기준을 확인한 뒤"에만 한다.

작업 중 설계서와 다르게 해야 할 이유가 생기면 먼저 `docs/decisions/`에 ADR을 쓰고 설계서의 해당 절을 고친 뒤 구현한다.
