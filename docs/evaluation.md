## 지표

Hit@k는 상위 k 청크의 페이지 집합과 gold 교집합 여부, MRR@10은 첫 적중 청크 순위의 역수다. 같은 페이지 중복은 추가 정답으로 세지 않는다. required Recall@5는 multi_evidence의 필수 페이지 포함 비율이다. 정답 없는 문항은 검색 정확도 분모에서 제외한다. degraded·HTTP 오류는 실패 및 0점으로 남기고 SHA 매핑 실패는 skipped로 별도 보고한다. 보류율·오보류율은 answers 실행에서 별도로 측정하며 fake 결과를 모델 품질로 해석하지 않는다. 인용 형식은 API 검증기로 확인하고 의미 정확도는 수동 검토가 필요하다.
