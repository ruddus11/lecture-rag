# 구현 진행보고

## 현재 상태 (2026-11-12)

M1~M6 기준 커밋은 `a292472`. 이어받은 미커밋 M7 UI·파일 API·테스트를 보존해 검토했다. 토큰은 메모리에만 저장하고 인증 세션마다 QueryClient를 교체한다. 기본 임베딩은 무료 로컬 bge-m3, 답변은 fake다. push는 수행하지 않았다.

## M7 검증

- API: `cd apps/api && uv run pytest` → 112 passed, 4 integration deselected. `uv run ruff check app tests`, `uv run mypy app` 통과.
- 웹: `cd apps/web && npm run typecheck && npm test && npm run lint && npm run build` (최종 결과는 handoff 참조).
- 브라우저: 실제 로컬 API·Qdrant·OpenSearch·bge-m3와 Chrome에서 로그인→PDF 업로드→ready→질문→근거 카드→PDF 3/3쪽→보류 화면 통과. fake 답변은 품질 평가가 아니다.
- `docker compose config`는 저장소 내부 standalone Compose로 검증. Docker daemon이 없어 컨테이너 기동·이미지 빌드 검증은 미실행.
- M8 범위의 파일 API는 M7 PDF 뷰어 검증에 필요하여 선행 구현. 요청마다 권한·ready 상태 확인, 전체/Range 응답 및 경로 이탈 방어 테스트 포함.

## 실행

Docker 환경: `cp .env.example .env` 후 `.env`의 AUTH_SECRET 설정, `docker compose up --build -d`. 로컬 검증은 `infra/local/README.md` 참조. 기존 개발 서버는 API 8000, 웹 5173이며 `infra/local/api.sh`의 기본 포트는 8010이므로 웹 프록시와 맞춰 8000을 지정한다.

## 남은 작업과 리스크

M8 삭제·재시도·캐시 골격·격리 회귀를 구현했다. fresh compose 검증이 불가능하여 M8 전체 완료와 v0.1 태그를 보류하고, 설계서의 마일스톤 완료 게이트에 따라 M9 이후로 넘어가지 않았다. M1 컨테이너 기동·메모리, M4/M6 유료 API smoke는 기존 미검증 상태를 유지한다. M9~M12 평가·성능·보안·CI 및 선택 M13은 아직 완료하지 않았다.


## M8 구현 및 검증

- 삭제 수신 즉시 원장 deleting·collection version 증가·캐시 clear, 워커는 두 엔진→파일→chunks 순으로 정리한다. 실패 시 비공개 상태를 유지한다.
- 재시도는 expected_version과 진행 중 작업을 확인하고 과거 작업의 최대 target_version+1로 시작한다. 삭제 실패는 delete 작업을 다시 등록한다.
- 캐시 키·TTL 골격을 연결했다. 임베딩/검색 실제 캐시 적중 경로는 M10 이전까지 사용하지 않는다.
- 삭제 전 대기 중 수집 작업이 문서를 failed로 되돌리는 문제와 생성 대기 중 삭제한 문서를 답변에 반환하는 문제를 각각 RED 테스트로 재현한 뒤 수정했다.
- 실제 Qdrant 1.20.0·OpenSearch 2.19.7/Nori integration 5 passed. integration 임베딩은 fake이며, bge-m3 브라우저 동작 검증과 구분한다.
- README 초안과 기관 A/B 문서·작업·파일·검색·인용 격리 회귀를 추가했다.

## 완료 게이트와 다음 한 작업

Docker executable/daemon이 없어 `docker compose down -v`→fresh 기동→전체 흐름은 실행할 수 없다. standalone Compose의 `config --quiet`만 통과했다. **M8 전체 완료와 v0.1 태그는 미완료**다. 다음 작업은 Docker 환경에서 README의 fresh compose 절차와 health/전체 흐름을 확인하고 로그를 남기는 것이다. M9~M13은 미착수다. 이 보류는 설계서 16장의 “완료 기준을 모두 만족해야 다음으로 넘어간다” 규칙을 따른다.
